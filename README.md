# xlsx

A Crystal shard for reading and writing XLSX files cmopatible with Excel.

## Installation

1. Add the dependency to your `shard.yml`:

   ```yaml
   dependencies:
     xlsx:
       github: nogginly/xlsx.cr
   ```

2. Run `shards install`
